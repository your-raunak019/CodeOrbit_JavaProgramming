🚀 Projects Overview
--------------------------------------------------
1. Task 1: Simple Calculator Program
A Java console application that performs basic arithmetic operations (+, -, *, /) using Scanner for interactive user input. Features robust exception handling for invalid inputs and division by zero.

2. Task 2: Student Grade Management System
A console application that manages student names and marks using dynamic ArrayList structures. Calculates and displays formatted summaries including average, highest, and lowest class marks.

3. Task 3: Bank Account Simulation
An Object-Oriented Java application simulating bank account operations (deposit, withdrawal, balance check). Includes balance validation to prevent overdrawing and maintains a structured transaction history log.
